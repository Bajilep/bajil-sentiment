# Bajil Sentiment

Bajil Sentiment is a simple Python library that classifies text as positive, negative or neutral.

## Features

- Positive sentiment detection
- Negative sentiment detection
- Neutral sentiment detection
- Simple Python interface
- No internet connection required

## Installation

```bash
pip install bajil-sentiment
```

## Usage

```python
from bajil_sentiment import SentimentAnalyzer

analyzer = SentimentAnalyzer()

result = analyzer.predict("This product is excellent")

print(result)
```
